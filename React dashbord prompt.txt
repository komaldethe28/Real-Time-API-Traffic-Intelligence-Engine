Build a **production-grade React dashboard** for a **Real-Time API Traffic Intelligence Engine**.

## Tech Stack (strict)
- React + Vite (**JavaScript only, no TypeScript**)
- Tailwind CSS
- Recharts
- Axios
- React Router

## Backend Integration
- Base URL: `http://localhost:3000`
- REST APIs:
  - `GET /api/v1/analytics/overview`
  - `GET /api/v1/analytics/flags`
  - `GET /api/v1/analytics/ip/:ip`
- WebSocket:
  - `ws://localhost:3000/ws?token=<WS_TOKEN>`

## Important backend response shapes (must match)
- `GET /api/v1/analytics/overview` returns:
  - `minutes: string[]`
  - `rollups: Array<{ total: number, topIps: Array<{ ip: string, count: number }>, topEndpoints: Array<{ endpoint: string, count: number }> }>`
  - `currentMinuteKey: string`
  - `blockedSample: Array<{ ip: string, reason: string }>`
- `GET /api/v1/analytics/flags` returns:
  - `items: Array<{ id: string, ip: string, reasons: string[], endpointKey: string, path: string, ts: number, meta: object }>`
- `GET /api/v1/analytics/ip/:ip` returns:
  - `{ ip, perMinute: Array<{ minuteKey: string, count: number }>, recentFlags: Array<flagItem> }`
- WebSocket messages:
  - `{ type: 'hello' | 'flag' | 'block' | 'throttle' | 'metrics_tick' | 'admin_unblock', payload: object }`

## Pages

### 1) Dashboard (`/`)
- KPI cards:
  - Total requests (latest rollup total)
  - Blocked IP count (`blockedSample.length`)
  - Optional: latest minute key
- Charts:
  - **Line chart**: requests over time (from `minutes + rollups.total`)
  - **Bar chart**: top IPs from latest rollup (`topIps`)
- “Top Endpoints” panel from latest rollup
- Auto-refresh REST data every 5 seconds
- Clickable IP rows/bars navigate to `/ip/:ip`

### 2) Alerts (`/alerts`)
- Professional table of anomaly events from `/analytics/flags`
- Columns: IP, Event Type(s), Endpoint, Path, Timestamp
- Event type comes from `reasons[]` (show badges)
- Highlight critical anomalies (`SPIKE_TRAFFIC`, `SCAN_PATTERN`) in red
- Merge real-time WebSocket events (`flag`, `block`, `throttle`) into table instantly
- Keep newest first

### 3) IP Detail (`/ip/:ip`)
- Header with IP and quick stats
- Line chart for request pattern (`perMinute`)
- Recent flags list/table (`recentFlags`)
- Red styling for suspicious reasons
- Back navigation to Dashboard

## UI/UX Requirements
- Dark theme, modern and clean (Cloudflare-like)
- Responsive layout (desktop + tablet + mobile)
- Sticky top nav/sidebar with:
  - Dashboard
  - Alerts
- Empty/loading/error states polished (skeleton or spinner + retry)
- Professional spacing, typography, shadows, subtle borders
- No basic/plain UI

## Architecture Requirements
- Modular file structure:
  - `src/components/*`
  - `src/pages/*`
  - `src/services/api.js`
  - `src/services/socket.js`
  - `src/hooks/*`
  - `src/utils/*`
- Reusable components (cards, chart panels, tables, badges)
- Use custom hooks for polling + websocket subscriptions
- Axios instance with base URL from env:
  - `VITE_API_BASE_URL=http://localhost:3000`
  - `VITE_WS_URL=ws://localhost:3000/ws`
  - `VITE_WS_TOKEN=<token>`
- Clean, production-ready code and naming
- No TypeScript files

## WebSocket behavior
- Connect once on app load
- Include token in query string
- Reconnect with exponential backoff
- Show subtle connection status indicator (Connected / Reconnecting / Offline)
- On incoming events, update Alerts immediately and refresh impacted dashboard data

## Deliverable
Generate a complete React frontend project scaffold and code that can run with:
- `npm install`
- `npm run dev`

Ensure all charts/tables are wired to real backend endpoints above, with graceful handling of missing/empty data.
