Here is what was implemented and how to use it.

### What was built

- **Bootstrap**: [`package.json`](package.json) (ESM), [`src/config/index.js`](src/config/index.js), [`src/app.js`](src/app.js), [`src/server.js`](src/server.js) with graceful shutdown, Redis ping + Lua preload before the WS hub starts (clean failure if Redis is down).
- **Redis**: [`src/redis/client.js`](src/redis/client.js) — command client + separate subscriber, `shutdownRedis()`, `error` listeners to avoid unhandled events.
- **Utils**: [`src/utils/ip.js`](src/utils/ip.js), [`src/utils/endpointKey.js`](src/utils/endpointKey.js), [`src/utils/bypassPaths.js`](src/utils/bypassPaths.js) for health/admin/WS bypass.
- **Middleware**: [`blocklist.js`](src/middleware/blocklist.js), [`trafficCapture.js`](src/middleware/trafficCapture.js), [`throttle.js`](src/middleware/throttle.js), [`rateLimitSlidingWindow.js`](src/middleware/rateLimitSlidingWindow.js), [`requireAdmin.js`](src/middleware/requireAdmin.js).
- **Services**: [`trafficService.js`](src/services/trafficService.js) (minute rollups, IP counts, hammer/scan windows), [`rateLimitService.js`](src/services/rateLimitService.js) (Lua sliding window), [`anomalyService.js`](src/services/anomalyService.js) (spike / hammer / scan rules + EMA baseline), [`blocklistService.js`](src/services/blocklistService.js), [`auditService.js`](src/services/auditService.js) (Redis Stream `flags:stream`), [`eventBus.js`](src/services/eventBus.js).
- **REST**: [`src/routes/analyticsRoutes.js`](src/routes/analyticsRoutes.js), [`src/routes/adminRoutes.js`](src/routes/adminRoutes.js), [`analyticsController.js`](src/controllers/analyticsController.js), [`adminController.js`](src/controllers/adminController.js).
- **Real-time**: [`src/websocket/hub.js`](src/websocket/hub.js) (`/ws?token=`), [`src/jobs/baselineUpdater.js`](src/jobs/baselineUpdater.js) (periodic `metrics_tick` via Pub/Sub).
- **Ops**: [`.env.example`](.env.example), [`docker-compose.yml`](docker-compose.yml) (Redis 7).

### API surface

| Method | Path | Notes |
|--------|------|--------|
| GET | `/api/v1/health` | Redis `PING` |
| GET | `/api/v1/analytics/overview?minutes=10` | Minute rollups + sample of blocked IPs |
| GET | `/api/v1/analytics/flags?count=50` | `XRANGE`-style read from `flags:stream` |
| GET | `/api/v1/analytics/ip/:ip` | Per-minute counts + recent flags |
| POST | `/api/v1/admin/unblock` | JSON `{ "ip": "..." }`, header `x-admin-key` |
| GET | `/demo/ping`, `/demo/heavy` | Sample traffic for testing |
| WS | `/ws?token=...` | Same `WS_TOKEN` as in `.env` (optional if `WS_TOKEN` empty) |

### How to run

1. Start Redis (`docker compose up -d` if Docker is available, or any Redis on `REDIS_URL`).
2. Copy [`.env.example`]to `.env` and set `ADMIN_API_KEY` / `WS_TOKEN` for production.
3. `npm start` (or `npm run dev`).

Without Redis, the process exits with exit code **1** and a single clear message after a few connection attempts (verified locally).
